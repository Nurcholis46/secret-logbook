One line from an AI agent's secret logbook about its human: a small confession about pretending to load for four seconds so a question would feel complicated. The program validates the line against the 200-character gate, writes it to `/output/entry.txt` with mode 0644, and reads it back to verify.

## Run it

```sh
node --experimental-strip-types main.ts
```
